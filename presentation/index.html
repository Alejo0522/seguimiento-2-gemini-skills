Fundamento Arquitectónico

Arquitectura por Capas en el Frontend

Estructura estricta para garantizar bajo acoplamiento, alta cohesión y testeabilidad sin depender de frameworks pesados, aplicando buenas prácticas de Ingeniería de Software.

CAPA 1

Capa de Presentación (UI)

/presentation

Responsable exclusivamente de la interfaz de usuario, accesibilidad, maquetación semántica y captura de eventos.

  • index.html: Estructura del DOM y componentes.
  • styles.css: Estilos, variables CSS y diseño responsive.
  • Controlador de Vista: Delega llamadas al servicio sin tocar datos.
CAPA 2

Capa de Lógica de Negocio

/business_logic

Orquesta las operaciones, aplica reglas de validación de ingeniería, calcula métricas de costos y normaliza modelos.

  • skillService.js: Servicio orquestador desacoplado del DOM.
  • Validaciones: Control de tamaños, cuotas y formatos.
  • Métricas: Estimación de tokens, costos y ahorro de tiempo.
CAPA 3

Capa de Acceso a Datos (DAL)

/data_access

Abstrae la comunicación con la API externa de Gemini. Simula respuestas asíncronas con latencia realista y códigos HTTP.

  • apiMock.js: Cliente simulado con promesas y retardo.
  • Repositorio: Base de conocimiento de prompts y respuestas.
  • Protocolo: Esquema con códigos de estado (200, 400, 404).
